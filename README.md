## ✨ Features

- **Multi-subject selection** — pick one or many subjects
- **3 difficulty levels** + Mixed mode
- **Flexible question count** — 10, 25, 50, 75, 100, or All
- **Optional timer** — 30s, 60s, or 90s per question
- **Instant feedback** with detailed explanations
- **Runtime option shuffling** — A/B/C/D positions randomize every session
- **Score ring animation** + grade + full question-by-question review
- **Dark mode** (auto + manual toggle)
- **100% offline** after first load — single HTML file, no server needed
- **Mobile-friendly responsive design**

## 📥 How to Use

1. Visit the live link above, OR
2. Download `index.html` and open in any browser — works completely offline

## 🛠️ Technical

- Single self-contained HTML file (~197 KB)
- Zero external dependencies — no CDN, no build tools
- All questions stored as static JavaScript
- Fisher-Yates algorithm randomises option positions on every load
- Hosted free on GitHub Pages
